Features

Overview

  • On the Options Panel, select the type of questions that you want
    • Ionic: select cations and anions
    • Covalent: simple and/or complex (explained below)
    • What type of question you want: ask for names or fomulas or both
  • Selecting covalent disabled ionic options. Unselecting the colvalent options will enable ionic options.
  • You now see the Question Panel
    • Type your answer to the question.
    • Click on "Check Answer" (or press Enter)
    • If it is correct, it will be recorded and you will get a new question.
    • If it is incorrect, you can try again.
  • Notes:
    • "sulphur" is always spelled as "sulfur".
    • Subscripts are entered automatically by the program. Just type in the number you want: H2SO4
    • Correct spelling of elements is essential: manganese(IV) sulfate
    • Correct placement of () in names and formulas is essential: (NH4)2CO3
    • Element symbols must have the correct case, but element names can be in any case.
  • Help panel
    • Ionic: F1 = list of selected cations and charges
    • Ionic: F2 = list of selected anions and charges
    • Ionic: F3 = help for this specific question
      This is quite detailed, so if you require it, it counts against your final score
    • Simple Covalent: F1 = help for covalent naming
    • Simple Covalent: F2 = list of non-metal oxidation numbers
    • Simple Covalent: F3 = not used
    • Complex Covalent: F1 = help for covalent naming
    • Complex Covalent: F2 = not used
    • Complex Covalent: F3 = list of complex covalent names and formulas
      Since this basically tells you the answer, using it counts against your final score
  • Summary panel
    After 20 questions (or whenever you click on [X]) the program will display your score and a summary of your questions.
    A list of all the correct questions is displayed along with a list of all of the questions which you got wrong.
    You have the option to create a PDF of this and save it, or send it to your chemistry teacher.

How it works

IONS.DAT file

All of the ions and covalent compounds that the nomenclature program uses are read from the file "ions.dat".

There are 9 different section headings in the file.
Each section can have up to 40 ions in it. Any more will be ignored. The spelling and format of the headings must be exactly as it is in the ions.dat file. Everything after a heading is considered part of that category until the next heading is reached or the end of the file is reached.

For example, everything under [Cations-monovalent] is considered to be a positively charged monovalent ion.

Lines beginning with a semi-colon are considered to be comments and are ignored as are blank lines.

All lines must have exactly the following format:

There are three fields, separated by commas. No spaces or other characters can be anywhere.

  • The first field is the name of the ion or element. This can be any case as the program will "uppercase" it anyway.
  • The second field is the formula or element symbol. The case must be correct here. Numbers are just typed in in regular case. No parentheses or charges are allowed.
  • The third field is the charge or oxidation number. Do not put in an + or - signs. If there are many possible charges (for positive ions only), then write the numbers in any order, but do not separate them.

Examples of correct formatting (the ions belong in different categories):

ammonium,NH4,1

carbonate,CO3,2

manganese,Mn,76432

The [Covalent-complex] section has a special format. There are only two fields: one for the name and the next for the formula.
Example of covalent-complex formatting:

methane,CH4

Question Generation

Ionic Compounds

If multiple cation or anion types have been selected, the program first chooses a random type(list) from that which has been selected. The program next randomly chooses a cation and an anion from those lists. If the cation is multivalent it randomly chooses a charge from the charges listed next to it.

The name is generated, adding Roman numerals in () for multivalent cations. The formula is generated based on the charges and reduced to the lowest common denominator. So Pb+4 and O-2 become Pb2O4 which is reduced to PbO2.

Covalent Compounds

To create a simple covalent compound, the program takes two elements at random from the simple covalent list of atoms, setting the least electronegative one as the first atom.

It then applies some rules, rejecting the choices and finding new atoms in the following situations

  • the two elements are the same
  • One of the elements has a zero charge (for + or -). This ensures that boron is never the second element.
  • Any compounds with H and C, N, or O. These have special names and go in the complex-covalent section
  • Any compounds with O and S or N. Same thing as above.

Other rules:

  • If the compound is Cl + F, Cl is always Cl1+
  • If there is a halogen and some other element, the halogen is always the second element.
  • If the compound is carbon + something, the formula is reduced to lowest common denominator (eg. C4+ and O2- ==> CO2)
  • The same thing is done for compounds where both elements have an oxidation number of 3. Thus B + N ==> BN.
  • Note that BP and BN have names "boron monophosphide" and "boron mononitride". Typically "mono" is not used for these two compounds.

Note: not all compounds actually exist in nature: e.g. As3+ and C4- give tetraarsenic tricarbide

Covalent compounds

These compounds have a name, and a formula, and possibly an alternative name dinitrogen monoxide,N2O,nitrous oxide
You can enter either name as the correct answer.

Entering answers

  • chemical names:
    • the case does not matter
    • for multivalent ions, () must follow the cation with no space between them
    • the valence must be in Roman numerals, but case does not matter
    • example: copper(II) chloride
  • formulas:
    • must have the correct case.
    • use ( ) where needed
    • numbers will automatically become subscripts
    • example: Ca(NO3)2
To check your answer, press <ENTER> or click on the check answer button.
If you get it wrong, you can fix it and try again.
If you click "I give up" then the correct answer will be displayed.

Score & Printout:

Your score is recorded in the top right corner.
After 20 questions, you are asked if you want to print out a list of the questions asked. This is because some teachers may want to mark it. The questions are printed to the default printer on your computer. An answer is only considered wrong if you press "I give up".
If you have pressed F3 for a question, the program notes "help needed" next to that question.
