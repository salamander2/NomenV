History

Acknowledgements

Thanks to Mr. Dennis Trankner who wrote a DOS nomenclature program in 1991 called "CHEMICAL NOMENCLATURE V 4.00", a.k.a. Nomen40.exe. Nomen40 was the inspiration for this program.

With his permission, I rewrote this as a Windows program using Visual Basic (v5.0).
When Visual Basis was no longer supported, a programmer named Zenista and I rewrote it all in Java in 2014.
Now in 2025, I have completely rewritten in as a web app using VueJS, Typescript, TailwindCSS, and Pinia.
